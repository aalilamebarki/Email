1.0 The Architectural Divide: Mocking vs Real Inboxes

API mocking intercepts outbound mail requests at the application boundary, returning simulated success payloads without ever transmitting RFC-compliant packets across SMTP relays. While useful for isolated unit testing, mocking fails to validate the entire production delivery pipeline. If your transactional mail provider changes header formats, DNS records fail, or HTML layout parsers break activation links, mocked tests pass blindly while real users are locked out.

Integrating true ephemeral mailboxes verifies the end-to-end lifecycle: database commits, SMTP transport, template generation, link encoding, and message parsing.

2.0 Playwright TypeScript Implementation

The following TypeScript snippet demonstrates creating a disposable mailbox, completing a registration form via Playwright, and asserting OTP validation cleanly:

signup.spec.ts 
import { test, expect } from '@playwright/test';

test('Full User Signup with Ephemeral Email', async ({ page, request }) => {
  // 1. Provision dynamic ephemeral address
  const inboxRes = await request.get('https://freetemp.email/api/inbox/generate');
  const { address } = await inboxRes.json();

  // 2. Complete web registration form
  await page.goto('https://example.com/register');
  await page.fill('input[name="email"]', address);
  await page.fill('input[name="password"]', 'EnterpriseSecret2026!');
  await page.click('button[type="submit"]');

  // 3. Poll ephemeral mailbox endpoint for incoming OTP
  let otpCode = '';
  await expect.poll(async () => {
    const res = await request.get(`https://freetemp.email/api/inbox/${address}/messages`);
    const data = await res.json();
    if (data.messages && data.messages.length > 0) {
      const match = data.messages[0].body.match(/\b\d{6}\b/);
      if (match) otpCode = match[0];
      return true;
    }
    return false;
  }, { timeout: 15000, intervals: [1000] }).toBeTruthy();

  // 4. Fill OTP in UI and verify dashboard entry
  await page.fill('input[name="verification_code"]', otpCode);
  await page.click('button[id="verify-button"]');
  await expect(page.locator('h1')).toContainText('Welcome to Dashboard');
});
