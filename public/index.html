بث فوري مباشر (WebSocket)

لا حاجة لتحديث الصفحة يدويا. يستيقظ الخادم عبر WebSocket Hibernation لحظة وصول البريد لبث الرسالة في أجزاء من الثانية.

تغطية شاملة لرسائل التحقق (Universal Verification)

يدعم كافة الصيغ: أكواد Google وSteam Guard و2FA وروابط التفعيل داخل الأزرار، مع نسخ فوري وتصفية التواريخ والتعقب.

عزل O(1) وحجب بكسلات التتبع

عزل كامل لكل صندوق عبر Durable Objects مع حظر وسوم التتبع الخارجية لحماية عنوان IP وهويتك بالكامل.

الخطوة 01

انسخ العنوان المعزول

يولد عنوان بريد خاص بك فوريا فور فتح الصفحة. اضغط زر النسخ والصقه في أي موقع يتطلب تسجيلا.

الخطوة 02

استقبل البريد حيا

تستقبل خوادم Cloudflare الرسالة وتقوم بتحليلها وبثها فورا إلى صندوقك المعروض أمامك دون أي تأخير.

الخطوة 03

انسخ الكود واحم هويتك

انسخ رمز OTP أو اضغط رابط التفعيل، ثم يتلف الصندوق وتمسح البيانات تلقائيا بعد 20 دقيقة أو بضغطة زر.

الأسئلة الشائعة

هل الخدمة مجانية بالكامل؟

نعم، الخدمة مجانية تماما وبدون أي رسوم خفية أو إعلانات مزعجة أو حاجة لإنشاء حساب أو إدخال بيانات شخصية.

كم تدوم صلاحية صندوق البريد؟

تدوم الصلاحية افتراضيا لمدة 20 دقيقة، ويمكنك تمديدها بضغطة زر (+10 دقائق) كلما احتجت لذلك، أو إتلاف الصندوق ومسح كافة محتوياته فورا.

هل يمكنني استقبال أكواد التفعيل (OTP)؟

نعم، تم تدريب محرك التحليل لاكتشاف كافة صيغ الأكواد العالمية (أرقام، حروف، رموز مقسمة بواصلة، رموز Google G-XXXXXX) وتوفير زر نسخ مباشر لها.

كيف تضمنون عدم اختلاط الرسائل بين المستخدمين؟

يعتمد النظام على خوارزمية Hashing حتمية O(1) لربط كل عنوان بحاوية Durable Object منفصلة تماما مع رمز أمان سري (Secret Token)، وتتم كافة العمليات داخل بنيتنا التحتية الخاصة على Cloudflare دون الاستعانة بأي طرف ثالث.
