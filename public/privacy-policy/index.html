سياسة الخصوصية

آخر تحديث: سبتمبر 2026

1. مبدأ الخصوصية التامة

نحن نحترم خصوصيتك كأولوية قصوى. تم تصميم خدمة "بريد مؤقت" لتعمل دون جمع أي معلومات تعريف شخصية، ودون طلب تسجيل حساب أو بريد إلكتروني بديل أو كلمة مرور.

2. مدة الاحتفاظ بالرسائل والإتلاف التلقائي

تتم إدارة كل صندوق بريد مؤقت بشكل معزول تماما، وتظل الرسائل المستلمة صالحة لمدة 20 دقيقة فقط. فور انتهاء هذه المدة، يتم حذف كافة الرسائل والنصوص والبيانات نهائيا من الذاكرة والتخزين بشكل آلي ولا يمكن استرجاعها.

3. عدم بيع أو مشاركة البيانات

لا نقوم ببيع أو تأجير أو مشاركة أي بيانات أو محتويات رسائل أو عناوين بريد إلكتروني مع أي أطراف ثالثة أو جهات إعلانية على الإطلاق.

4. ملفات تعريف الارتباط (Cookies) والتعقب

موقعنا لا يستخدم ملفات تعريف ارتباط لتتبع المستخدمين أو إنشاء ملفات تعريف سلوكية عبر الإنترنت. الاتصال مشفر دائما باستخدام بروتوكول HTTPS و Secure WebSockets.

5. التواصل معنا

إذا كانت لديك أي استفسارات حول سياسة الخصوصية، يمكنك التواصل معنا عبر موقعنا الرسمي.
